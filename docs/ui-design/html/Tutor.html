List comprehension trong Python

AI Tutor nhớ ngữ cảnh trong phiên này

Giải thích list comprehension giúp mình, kèm ví dụ.
List comprehension là cách viết ngắn gọn để tạo danh sách mới từ một dãy có sẵn, có thể kèm điều kiện lọc.
# bình phương các số chẵn
squares = [x * x for x in range(10) if x % 2 == 0]
print(squares)  # [0, 4, 16, 36, 64]
